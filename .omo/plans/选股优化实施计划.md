# 选股优化实施计划

## 依赖关系

```
Step 1 (独立): 形态选股免费化 → allStockList.vue 3处修改
Step 2-5 (顺序依赖):
  2. models/daily_pick.go 扩展字段
  3. StrategyContext 扩展
  4. 3个新策略实现
  5. DailyPickEngine 集成
Step 6 (独立): AI prompt 改造
Step 7 (最终): 构建验证
```

## 执行顺序

### Step 1: 形态选股免费化
- 文件: `frontend/src/components/allStockList.vue`
- 改动: 移除 3 处 VIP 门槛 (onMounted, loadStocks, handleCheckedChange)
- 验证: lsp_diagnostics

### Step 2: 模型扩展
- 文件: `backend/models/daily_pick.go`
- 改动: 新增 IndustryScore / ResearchScore / MacroScore 字段
- 验证: 编译通过

### Step 3: StrategyContext 扩展
- 文件: `backend/data/strategy.go`
- 改动: 新增 IndustryCode / IndustryRankScore / Macroscore
- 验证: lsp_diagnostics

### Step 4: 3 个新策略实现（可并行）
- 新建 `strategy_industry.go` - 行业强度
- 新建 `strategy_research.go` - 研报热度
- 新建 `strategy_macro.go` - 宏观环境
- 验证: 各自编译通过

### Step 5: DailyPickEngine 集成
- 文件: `backend/data/daily_pick_engine.go`
- 改动: 预取逻辑、新策略注册、RunDailyPick 透传数据
- 验证: 构建通过

### Step 6: AI prompt 改造

### Step 7: 构建验证
- `go build` 全量编译
