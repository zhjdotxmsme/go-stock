1. 已确认的关键决策

D1 并行体系：新建 backend/data/khunter/ 独立模块，不改动现有三套策略/评分体系（strategy_*.go、daily_pick_engine、agent/strategy/scoring）。表统一 khunter_ 前缀。
D2 全量移植：范围包含五维评分 + VaR 风控 + 凯利仓位 + 回测，一次到位。
D3 回测复用：复用现有 backend/data/backtest/ 引擎，通过适配层翻译信号；凯利仓位作为引擎的仓位策略选项注入。KHunter 的加仓取大者/亏损冷却/PTrade 实盘规则不移植。
D4 完整前端：新增"狩猎场"路由页，含评分排行（雷达图）、策略信号、回测结果、风险看板 4 个 tab，Vue3 + Naive UI + ECharts。
D5 资金流历史落库：新增 khunter_money_flow_daily 表，避免全市场评分时逐股实时拉东财接口被限流。
D6 半凯利：采用 f*/2，clamp 到 [0, 15%]（KHunter 代码实际是全凯利 clamp 30%，注释声称半凯利系错误）。
D7 漏斗式评分：先跑形态策略扫全市场（纯本地 K 线计算），再只对候选池（预计几十只）做五维评分。交易日 17:00 自动执行，支持手动触发。

4. 形态策略规格（5 个）


以下参数均取自 KHunter 代码实际生效值（非注释）。所有策略过滤 ST/退市股；数据长度不足直接出局。





4.1 仙人指路 ImmortalGuidance（数据 ≥30 根，技术权重 70）


    
  
  • 信号日（T-1 ~ T-3 内寻找）：冲高幅度 (high−昨收)/昨收 ≥ 8%；上影线/high ≥ 4%（阳线：high−close，阴线：high−open，不要求收阳）；量比 ≥ 1.5（对前 5 日均量，不含当日）；MA5 > MA10 > MA20 多头排列
    • 
  
  • 趋势过滤：最近 20 日收盘价 OLS 线性回归，slope > 0 且 R² ≥ 0.5
    • 
  
  • 反包确认（今日）：close ≥ MA5 且 close ≥ 上影线 50% 位置（阳线 (close+high)/2，阴线 (open+high)/2）；信号日至今日之间不得有提前反包（中间某日已反包则信号作废）
    • 








4.2 W 底 WBottom（数据 ≥60 根）


    
  
  1. 预检：近 5 日存在涨幅 > 5% 的交易日；存在"放量确认日"（涨幅 > 8% 且量 ≥ 前5日均量 × 1.2）
    2. 
  
  2. 形态：排除最新 5 日，在 40 日窗口找局部低点（5 日 LLV，容差 1e-6）；取最近两个低点 L1/L2，价差 ≤ 3%，间隔 > 10 个交易日；颈线 H = 两底间最高价，要求 H ≥ L1 × 1.1
    3. 
  
  3. 突破：放量确认日 close ≥ H × 1.01，且其前一日 close < H
    4. 
  
  4. 趋势：MA10 > MA30
    5. 
  
  5. 假底过滤：L1 之前 30 日内最高价 > L1 × 1.2（确有 ≥20% 深跌）；突破后至今所有 close ≥ H × 0.98
    6. 








4.3 涨停回马枪 LimitUpPullback


    
  
  • 近 6 日内有涨幅 ≥ 9.5% 的涨停日，当日量比（对前5日均量）≥ 2.2
    • 
  
  • 回调期（涨停日至今，1~9 天）：振幅 ≤ 15%；所有收盘 ∈ 涨停收盘 × [0.95, 1.05]；至少一日收盘低于涨停收盘；至少一日量 ≤ 涨停日量 × 0.5（缩量）
    • 
  
  • 今日：涨幅 > 2%，量 ≥ 昨日 × 1.5，close > MA5
    • 








4.4 底部趋势拐点 BottomInflection（数据 ≥120 根）


    
  
  • 锚点（倒序第 3~5 根中的放量长阳）：涨幅 > 8%；量比（对前10日均量）≥ 2.5；close 距 120 日最低价 ≤ 15%；锚点后至今所有 close ≥ 锚点开盘价
    • 
  
  • 深跌确认：120 日窗口内先出现最高价、后出现最低价，(最高−最低)/最高 > 45%
    • 
  
  • MACD 底背离：锚点前 20 日分前后两半（各 10 日），后半段 low 创新低 且 后半段 MACD 柱 > 前半段（不创新低）。MACD 参数 12/26/9，EMA 用递推式 ema = α·x + (1−α)·prev（pandas adjust=False 口径）
    • 








4.5 主升低吸 MainUptrendDipBuy（数据 ≥106 根）


    
  
  • 一拉：最近 60 日窗口内按高度从高到低扫 swing high（严格大于左右各 2 根），取首个满足 (H−L)/L ∈ [30%, 100%] 的 H，L = H 之前 45 日最低价
    • 
  
  • 二调：H 之后最低点 P：回撤 (H−P)/H ≥ 18%，且 < 一拉涨幅 − 8%，且 P > L
    • 
  
  • R：H 之后、今日之前最后一个 swing high，且 R < H
    • 
  
  • 今日突破：阳线实体 (C−O)/O ≥ 5%；C > R 且 (C−R)/R ≤ 2%（贴紧不追高）；量比 ≥ 1.8；C > MA5
    • 






不移植项：龙头策略（依赖 tushare 涨停池：封板时间/炸板/连板，go-stock 无对等数据）；KHunter 策略中的死代码参数（仙人指路 body_length/volume_ratio_max、W底 KDJ/知行线展示指标）不移植。



5. 五维评分系统




综合分 = 技术×0.35 + 资金×0.35 + 基本面×0.10 + 板块×0.10 + 事件×0.10。任一维度触发一票否决 → 总分直接 = −100（淘汰）。



  
等级分数区间

  
强烈推荐≥ 80

  
推荐60 ~ 79

  
中性40 ~ 59

  
谨慎20 ~ 39

  
回避< 20

  
淘汰= −100（veto）





5.1 技术面（35%）


得分 = Σ 命中策略权重，权重表存 JSON 配置（khunter_strategy_weights.json）支持热加载：底部趋势拐点/趋势加速/阻力位突破/W底/多金叉/启明星/仙人指路/2560/主升低吸等 +50，超跌反弹/低位九转 +60，龙头 +90（预留，策略未移植时不出现），M头 −80、多死叉 −50。否决：M头 + 多死叉同时命中 → −100（一期未移植这两个负向策略，否决规则保留配置位）。



5.2 资金面（35%）


得分 = 主力净流入×0.55 + 大单占比×0.10 + 北向×0.10 + 方向×0.25（北向数据 go-stock 暂无对等源，一期该子项固定给中性分，权重按比例暂并入主力净流入，配置化预留）。


    
  
  • 主力净流入（5 日累计）：>1亿→100；>5000万→80；>100万→60；>0→40；=0→30；<0→−20
    • 
  
  • 大单占比（近 5 日逐日累加）：>5%→+40；>1%→+20；>0→+10；<0→−30
    • 
  
  • 方向：大单>0 且小单<0（吸筹）→100；大单>0 且小单≥0→60；大单<0 且小单>0→−100（待否决）；其他→0
    • 
  
  • 否决：① 5日主力净额 < −1亿 且 大单净流入占比（5日均值）< −5%；② 出货信号：大单净流出占比 > 1% 且小单净流入占比 > 1%（5日均值）
    • 




5.3 基本面（10%）


得分 = 50 + 净利润同比（>30%:+20 / 0~30%:+10 / <0:−20 / 缺失:0）+ ROE（>15%:+20 / 5~15%:+10 / 0~5%:0 / <0:−20）+ 经营现金流/收入（>1:+20 / 0~1:+10 / <0:−20），截断 [−100, 100]。取数严格用 end_date ≤ 评分日的最新一期（防未来函数）。否决：净利润同比 < −50%，或 ROE < −5%。数据源：东财 F10。



5.4 板块强度（10%）


板块得分 = 50 + 当日涨幅进全市场前 20（+50）+ 板块当日资金净流入 > 1亿（+50）/ ≤ −1亿（−50）；个股得分 = 其所属行业/概念板块得分的 MAX。数据源：AllStockInfo 归属 + bk_fund_flow/concept_fund_flow 落库表。



5.5 事件驱动（10%）


得分 = 50 + Σ 事件分，截断 [−100, 100]。一期实现规则版分类器，数据源为现有公告（StockNotice）/龙虎榜/大宗交易/减持接口：



  
事件分值有效期

  
业绩预增（增幅>50%）+2020 天

  
业绩略增/预增≤50%+1020 天

  
股东增持+2050 天

  
股票回购+1050 天

  
龙虎榜机构净买入+105 天

  
业绩预减/首亏−2020 天

  
业绩略减−1020 天

  
股东减持−3050 天

  
异常波动公告−1510 天

  
大宗交易折价>5%−105 天

  
龙虎榜净卖出−105 天




否决：① ST/*ST；② 业绩暴雷（预减幅度 < −80%，或首亏且净利 < 0）；③ 大股东减持（控股股东/实际控制人/5%以上股东）。LLM 打标作为二期增强预留接口。





6. 风控与仓位






VaR（risk/var.go）


    
  
  • 对沪深300日收益率序列（窗口 500 日，最少 100 日，|r| ≤ 20% 校验）
    • 
  
  • hybrid = 0.4 × 历史分位 + 0.6 × EWMA（λ=0.94，加权分位 + 线性插值），99% 置信度
    • 
  
  • 5 日 VaR = 单日 × √5；ES = 所有 < VaR 的收益率均值
    • 
  
  • 数据不足时按"注意"档保守处理
    • 







风险四档（risk/level.go）



  
等级VaR(1d)仓位上限选股分加成

  
正常> −3%100%+0

  
注意−3% ~ −5%70%+5

  
危险−5% ~ −8%40%+15

  
崩溃≤ −8%0%（清仓信号）+999










半凯利仓位（risk/kelly.go）


f* = (p×b − q) / b（p=胜率，q=1−p，b=盈亏比），取 f*/2，clamp 到 [0, 15%]；建仓金额 = 总资金 × f*/2，向下取整 100 股整数倍，< 最低金额（100 元）→ 0。每策略独立配置 p/b（初始 p=0.40、b=1.5 → 仓位 ≈3.3%），回测跑出实测胜率/盈亏比后回填。单日买入数量上限、止损倍数随风险档位缩放。





7. 每日流水线与调度




交易日 17:00 自动执行（复用项目现有定时任务机制），支持前端"立即运行"手动触发：


1. K线增量更新（复用现有同步逻辑）
2. 5 个形态策略并行扫描全市场（纯本地 kline_bars，goroutine 并发）
3. 汇总候选池（去重，预计几十只），信号落 khunter_signals
4. 候选池数据预取：资金流历史落库 → 基本面 F10 → 板块 → 事件打标
   （信号量限流，控制东财接口节奏；单股失败按 degraded 处理）
5. 候选股五维评分 → 落 khunter_scores
6. 计算大盘风险档位 → 落 khunter_risk_level
7. 狩猎场筛选：总分 ≥ (60 + 风险分加成) 且 现价 ≥ 支撑位 × 0.98 → 落 khunter_hunting
8. 已在狩猎场的股票每日更新追踪（track_days +1，破位移除）


支撑位计算一期采用简单规则：近 20 根收盘价的最低值（KHunter 的支撑位计算器较复杂，二期可细化）。





8. 回测适配




    
  
  • backtest_adapter.go 将 khunter 的 Signal 结构翻译为现有 backend/data/backtest/ 引擎的输入格式，是该引擎的唯一对接点。
    • 
  
  • 凯利仓位作为现有引擎的仓位策略选项注入（不修改引擎核心，若引擎接口不支持自定义仓位策略，则先以固定仓位跑信号级验证，凯利仅用于前端展示建议仓位）。
    • 
  
  • 回测产出：每策略的胜率、盈亏比、收益率、最大回撤 → 回填凯利配置的 p/b。
    • 
  
  • KHunter 的加仓取大者、亏损冷却 21/250 交易日、PTrade 实盘规则不移植。
    •

10. 错误处理与测试




    
  
  • 降级：K 线走现有四源降级；资金流/基本面/事件拉取失败时该维度按中性分处理并标记 degraded=true，流水线不中断。
    • 
  
  • 单股隔离：候选池中单股评分失败仅记录日志跳过，不影响其他股票。
    • 
  
  • 策略测试：每个策略表驱动测试 —— 构造 K 线正例（命中）≥1、反例（不命中）≥1、边界（数据长度不足/停牌无当日K线）。
    • 
  
  • 评分测试：权重计算、六档评级边界、一票否决优先级（veto 覆盖正常加权）。
    • 
  
  • 风控测试：VaR 三种方法数值对照、四档边界、半凯利 clamp 与取整。
    • 
  
  • 回归基准：可用 KHunter 对同一只股票同一日期的选股结果做人工抽查比对（两侧数据源不同，允许因复权/数据差异导致的个别不一致，重点核对逻辑口径）。
    • 






11. 移植陷阱清单（以 KHunter 代码实际行为为准）




    
  
  1. K 线方向：KHunter 全程倒序（index 0 = 最新），go-stock 正序。所有 iloc[0]/iloc[-1]、滚动窗口方向需逐处换算。
    2. 
  
  2. 均量口径：所有"前 N 日均量"均为 shift(1) 后 rolling —— 不含当日。
    3.
