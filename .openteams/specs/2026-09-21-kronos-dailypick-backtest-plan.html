日期：2026-09-21 ｜ 项目：go-stock ｜ 状态：范围已确认（全四阶段）

一、背景与思路

已接入的 Kronos K线预测（见 2026-09-21-kronos-kline-prediction-design.html）目前是独立的展示功能。 本规划把它升级为推荐体系中的一个前瞻性因子，并借助现有复盘（DailyPickReview）与回测（backtest）机制形成有效性闭环： 预测 → 推荐采用 → 复盘验证 → 自动调权。核心原则：先验证、后放量——Kronos 因子权重由复盘数据驱动，长期失效自动降权到零。

模块能力本规划的用法

DailyPickReviewT+1/3/5 收益率复盘、胜率统计、策略乘数调权同步评估 Kronos 预测命中，驱动因子调权

二、总体架构

每日推荐流程（增强后）：
  候选股 → 硬过滤 → 多策略打分 → 九因子增强
      → 【新】Kronos 因子：TopM(30) 批量预测 → 方向×涨幅×一致度 → 因子分
      → 风险覆盖 → LLM 二次排序 → 轮动 → 落库（含 kronos 预测字段）
                                          │
复盘流程（增强后）：                        ▼
  T+1/3/5 实际收益回填 ←── 比对 ── Kronos 预测 vs 实际（方向命中率、IC）
      → 因子胜率/IC 趋势 → 策略乘数表自动调权（复用 loadStrategyMultipliers）

回测引擎（新增信号源）：
  历史切点 → Kronos 预测 → 涨幅>X% 入场 → backtest.Engine → 超额收益/回撤
  滚动批量回测（N 切点 × M 股）→ 方向准确率分布 → 参数寻优

三、分阶段设计

P1Kronos 预测因子接入每日推荐

  • 打分流程末尾（LLM 排序前）对 TopM=30 候选调用 Kronos predict_batch（新增 Python 端 /predict_batch，GPU 并行、CPU 逐只回退）；
  • 因子分：score = clip(预期涨幅%, -10, 10) × (一致度/100)，映射到 0~100 并入总分（初始权重低，如 5%）；预测下跌（方向 down 且跌幅 >1%）额外降权；
  • daily_pick 表新增列：kronos_direction、kronos_change_pct、kronos_confidence（AutoMigrate）；
  • 设置页开关「推荐启用 Kronos 因子」，默认关；服务离线/超时时该因子静默跳过；
  • 性能预算：CPU 每批 30 只预计 1~3 分钟，打分阶段进度条提示。

P2因子有效性复盘闭环

  • DailyPickReview 复盘时同步比对：Kronos 方向 vs T+1/3/5 实际涨跌 → 命中标记；预测涨幅与实际涨幅的 Rank IC；
  • 复盘汇总新增 Kronos 区块：近 30 日方向胜率、IC 均值、滚动趋势；
  • 自动调权：复用策略乘数机制——近 30 日胜率 ≥55% 且样本 ≥20 时权重上浮（最高 15%），胜率 <45% 降权，<40% 归零；
  • 调权动作写日志 + 复盘页可见（可人工锁定权重）。

P3回测引擎 Kronos 信号模式

  • backtest.Input 新增信号源 SignalSource: "kronos" + 入场阈值（预测涨幅 > X%）：在历史信号日跑 Kronos 预测（Python 端支持指定截止日期切点），满足条件才入场；
  • 滚动批量回测（借鉴官方 yuce/historical_backtest.py）：N 个历史切点 × M 只股，输出方向准确率分布、信号策略资金曲线 vs 基准、最大回撤；
  • 参数寻优：复用 optimizer.go 对 lookback(50~400) / pred_len(5~20) / T(0.8~1.5) 网格寻优；
  • 结果缓存到本地表，避免重复推理。

P4前端呈现

  • 每日推荐列表：Kronos 预测列（方向 + 预期涨幅 + 一致度）+ 复盘命中标记（✓/✗）；
  • K 线图预测面板：新增「回测模式」——历史切点预测 vs 真实走势对照（facecat 式分割线画在历史中段）+ 误差统计（方向对错、收盘平均偏差）；
  • 复盘页：Kronos 因子胜率/IC 趋势图；
  • 推荐详情 K 线上直接叠加该股的 Kronos 预测。

五、降级与风险

  • 全程降级：Kronos 未开启/离线时，推荐、复盘、回测流程与现状完全一致；
  • 性能：CPU 推理限制 TopM=30 + 批量接口 + 结果缓存；超时（单批 5 分钟）直接跳过因子；
  • 过拟合风险：P3 寻优结果只用于 P2 调权的参考，不直接改线上权重；
  • 预测免责声明：所有预测展示位保留「模型推演，非投资建议」标识。
