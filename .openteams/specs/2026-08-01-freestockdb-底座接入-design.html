日期 2026-08-01 项目 go-stock 状态 已评审待实施

1. 背景与目标

free-stockdb 是一个 A 股本地量化数据引擎：数据落盘在本地 LevelDB，通过 127.0.0.1:7899 的 HTTP K-V 接口提供日K、分钟K、复权因子、板块等数据。本设计将其接入 go-stock 现有的数据源统一路由层（backend/data/datasource），作为最高优先级数据源，覆盖走 Router 的全部功能（回测、每日选股、Agent 工具、指标计算）。

  • 范围：统一路由层最高优先级源（前端 K 线图等直连路径本期不动）
  • 能力：K线 + 报价 + 板块 + 指标计算，四种全接
  • 生命周期：设置页配置 stockdb.exe 路径，go-stock 启动时自动拉起并管理
  • 指标：Go 全量移植 39 指标 + 金叉信号 + 5 种指数加权
free-stockdb 的 HTTP 服务本质是 K-V 存储；README 宣称的「39 指标、复权、周月K聚合」全部在其 Python 客户端层（zhibiao.py + 二进制 zb_core 模块、stock_sdk.py）实现。因此 Go 侧需自行移植语义层。其中 XSII / DFMA / KTN / TAQ 等非标指标无公开源码定义，只能按同名经典公式实现，数值不保证与 zb_core 逐位一致。

4. 数据流

回测 / 选股 / Agent 工具 → Router.GetKLine → freestockdb.Provider (Available? 探测 7899；否则降级 TDX → 东财) → kline.go: GetData(code, start, end, freq, fq) → client.Get("日k:600633:20260620>20260626") HTTP → 127.0.0.1:7899 → 复权折算 (qfq/hfq 时；因子来自预载的 复权*:cum 内存缓存) → 周期聚合 (1w/1M/5m/15m/30m/60m 时) ← 命中后 Router 异步写 SQLite 缓存 (现有逻辑不变)

5. 语义移植规则（严格对照 stock_sdk.py）

5.1 键表达式构造

  • 单日：日k:code:YYYYMMDD；范围：a>b 升序 / a<b 降序；通配：202606*
  • 分钟K查询给 8 位日期时自动补全 14 位：start+000000、end+235959
  • N 表示最新记录；start/end 均缺省时用 *

5.2 复权折算

  • 启动时一次性拉 复权* 的 cum 因子到内存：每只股票两个平行数组（日期串、cum 值），LevelDB 返回天然有序无需排序
  • 折算时对每条记录二分查找 <= 记录日期(取前8位) 的最大除权日因子 f_current
  • qfq：ratio = f_latest / f_current；hfq：ratio = 1 / f_current
  • 对 open/high/low/close/pre_close 除以 ratio；股票（非 1/5 开头）保留 2 位小数，基金（1/5 开头）保留 3 位
  • |ratio - 1| < 1e-6 时跳过；无因子记录的股票视为不复权直接透传

5.3 周期聚合

  • 周/月K：日K按 ISO 周 / 年月分组；open 取首、high/low 取极值、close 取末、volume/amount 求和；pre_close 取上一周期 close；pct_chg / amplitude 重算；turnover 求和、vol_ratio 求均值；pe/pb/市值/股本/is_st 取周期末截面；停牌缺记录的分组跳过
  • 分钟聚合：1m → 5/15/30/60m，按交易时段对齐（9:30–11:30 / 13:00–15:00），elapsed 映射算法照搬 _merge_minutes_to_period：9:30–11:30 映射 elapsed 0–120，13:00–15:00 映射 121–240；按对齐结束时刻分组，日期键 = ymd*1000000 + HHMM00

5.4 板块索引

  • 启动时拉 板块* 全量，构建 BoardIndex：by_code / by_stock / by_name（类别_名称 键）/ by_category 四向索引
  • 提供 bk.get 等价查询：股票→板块、板块→成分股、板块名模糊匹配（子串）、按 category 取全集、fields 投影
  • 股票代码统一取 . 前 6 位；索引随进程重启或定时（每小时）刷新

5.5 报价

  • free-stockdb 无独立实时报价接口：QuoteProvider 用 日k:code:N（最新一根日K，含 pre_close / pct_chg / 市值 / PE 等字段）实现
  • 日内分钟级实时报价仍由现有东财/腾讯链路承担（QuoteProvider 降级链不变）

5.6 指标引擎（indicator 包）

  • 输入为 K线数组（与数据源无关），输出与 zb.get 同构：[{date, ma5, k, d, j, dif, dea, macd, ...}]，单股返回 list、多股返回 {code: list}
  • 参数对齐 zb.get：单指标 n=5 或 "5,10,20"；多指标 n=["5,10,20", null, "12,26,9"] 与 name 一一对齐，缺省用各指标默认参数（macd 12,26,9；kdj 9,3,3；boll 20,2；bias 6,12,24；xsii 102,7 等）
  • 金叉：cross=true 只返回信号（1 金叉 / -1 死叉 / 0 无），cross=with_value 同时返回指标值与信号；多指标时所有单项均为 1 则综合 cross 为 true
  • 指数 zhishu：method 1 等权 / 2 流通市值 / 3 成交额 / 4 成交量 / 5 总市值，base=1000；分钟级数据无市值字段时 method 只允许 1/3/4
  • 39 指标清单：趋势 MA EMA SMA WMA DMA EXPMA TRIX DMI DFMA BBI；震荡 MACD KDJ RSI WR CCI PSY BIAS ROC MTM DPO；通道 BOLL KTN TAQ；量价 OBV VR EMV MFI CR MASS；综合 ATR ASI BRAR XSII STD SUM HHV LLV REF

6. 错误处理

场景行为
manager 拉起失败 / 健康检查超时5s 间隔轮询 7899 最多 10 次；失败记日志、provider 标记不可用，Router 自然降级，不阻断启动
运行中 free-stockdb 挂掉client 请求失败 → provider 返回 error → Router 降级下一源；Available() 结果缓存 30s，避免每请求探测
单股无数据返回 error，由 Router 降级到下一源（与现有 TDX/东财 chain 契约一致）
复权因子缺失（新股）视为不复权，透传原始数据
指标名非法 / 参数不齐返回明确 error，与 zb.get 报错行为一致
进程退出go-stock 退出时回收 stockdb 子进程（仅当由 manager 拉起）；用户自行启动的实例不动

8. 明确不做（YAGNI）

  • 不接入 tick 级数据
  • 不使用 free-stockdb 的 rd 正则 / 类SQL 查询器
  • 不做港股、美股
  • 不动前端 K 线图的直连数据路径（本期只覆盖 Router 统一层：回测、选股、Agent 工具、指标）
  • 不内嵌 free-stockdb 发行包到 go-stock 安装包
