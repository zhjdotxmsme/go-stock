统一信号引擎与选股/持仓融合

日期：2026-09-22 · 状态：已确认 · 分支：feat/multi-agent-analysis

1. 背景与问题

当前四处信号相关能力各自为政：

  • 形态选股（allStockList.vue）：30 个条件经后端拼接为东财选股 API 的 filter 表达式，形态判定由东财服务器完成，本地无形态识别逻辑，黑盒不可解释、离线不可用、无法做历史时点判定。
  • 指标选股（SelectStock.vue）：组合策略 + 自然语言问财，与形态选股条件体系不互通。
  • K线分析：38 个技术指标本地计算（tool_indicator.go / GetTechnicalIndicators），仅用于单股图表，与选股条件无共享。
  • 交易记录：持仓/交易与上述信号完全隔离，看不到持仓当前命中什么信号。

2. 目标

  • 建立本地统一信号引擎：指标信号 + K线形态 + 量价/资金信号的统一判定与元数据（名称/类别/方向/说明）。
  • 交易记录融合：持仓信号徽章、买入时机快照、逃顶预警。
  • 选股页面合并为统一工作台：东财粗筛 + 本地引擎精筛/验证。

3. 架构

backend/data/signal/            ← 新增信号引擎（纯函数，K线输入 → 命中信号列表）
    types.go      SignalDef / SignalMatch / Direction / Category
    registry.go   信号注册表（30 个信号定义，说明文案前后端共用）
    indicators.go MACD/KDJ/MA 等基础计算（复用 tool_indicator 算法口径）
    patterns.go   K线形态识别（18 种）
    engine.go     Evaluate(bars, asOfIdx) 批量判定；资金流信号经 Provider 注入

消费方：
  P2 持仓徽章：TradingRecordHandler.GetHoldingsSignals() → 持仓列表「信号」列
  P3 时机快照：TradingRecord.SignalSnapshot (JSON) 保存买入时自动填充
  P3 预警：持仓逃顶信号 → 系统通知（同股同信号同日仅一次）
  P4 工作台：新页面合并 形态选股+指标选股，结果加「本地验证」列

5. 各阶段设计

P1 信号引擎

  • Evaluate(bars []data.KLineData, asOfIdx int) []SignalMatch：asOfIdx 支持历史时点截断判定（时机快照依赖）。
  • 判定阈值集中为常量并附注释（如大阳线=实体涨幅≥4% 等），单测用合成K线验证命中/不命中。
  • 资金流信号通过 FundsFlowProvider func(code string) (netInflow float64, ok bool) 注入；未注入或失败时这两项不参与判定。

P2 持仓信号徽章

  • 后端：TradingRecordHandler.GetHoldingsSignals()——取当前持仓 → 批量 Evaluate（goroutine 并发 + 当日缓存）→ 返回 code → []SignalMatch。
  • 前端：持仓列表新增「信号」列，多头绿色/空头红色标签，悬停显示说明（文案来自引擎注册表，与选股页一致）。

P3 时机快照与预警

  • TradingRecord 增加 SignalSnapshot string（JSON）；保存买入记录时自动 Evaluate 存快照；详情/复盘显示「当时信号 vs 事后走势」。
  • 预警：应用启动/每日复盘后检查持仓逃顶类信号（乌云盖顶、黄昏之星、射击之星、穿头破脚、高位净流出），命中即系统通知，同股同信号同日去重。

P4 统一选股工作台

  • 新页面 ScreeningWorkbench.vue：左侧条件面板（30 条件 + 组合策略 + 自然语言），右侧结果列表。
  • 结果列表「本地验证」列：引擎对东财粗筛结果逐只复核，标注实际命中信号（暴露东财黑盒与本地的差异）。
  • 菜单合并：形态选股/指标选股入口重定向到工作台；旧组件摘除路由保留代码。

6. 边界与权衡

东财与本地判定可能不一致：东财形态定义不透明，工作台「本地验证」列有意暴露差异而非掩盖。
  • 引擎仅做日K级别；分钟级形态不在本期。
  • Kronos（ML 预测）不并入信号引擎（统计模式识别 ≠ ML），工作台结果可叠加既有 Kronos 列。
  • 资金流/人气排名依赖外部接口，失败降级跳过，不阻塞。

7. 验证

  • 信号引擎：合成K线单元测试覆盖全部 30 个信号的命中/不命中路径。
  • 持仓徽章：含已知形态的自选股验证标签显示。
  • 回归：原形态选股 API（东财筛选）行为不变；go build / vet / 相关测试全过。
