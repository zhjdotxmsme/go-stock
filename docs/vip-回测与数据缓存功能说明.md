## 1. 功能概述

本次新增的三大核心功能针对 AI 推荐股票的实际表现验证与本地数据持久化需求：

| 功能 | 入口 | 作用 |
|------|------|------|
| **单次回测** | 回测验证页 → 单次回测 | 对单条信号模拟买入持有，结算收益/胜率/最大回撤 |
| **批量回测** | 回测验证页 → 批量回测 | 按日期范围批量模拟交易，输出 Sharpe、WinRate 等统计 |
| **数据管理** | 数据管理页 | 查看 K-Line 缓存统计、启动全市场历史数据同步 |

## 2. 回测验证

### 2.1 入口

点击左侧导航菜单 **「回测验证」**（图标：📊），进入回测验证页面。页面分为两个功能卡片：**单次回测** 和 **批量回测**。

### 2.2 单次回测

对一条具体的买入信号进行模拟交易。

| 参数 | 说明 | 示例 |
|------|------|------|
| 股票代码 | A 股代码（必填） | `sh600519` |
| 信号日期 | 推荐/信号产生的日期 | `2026-06-20` |
| 买入价格 | 0 表示用信号日收盘价 | `0` |
| 持有天数 | 买入后持有 N 个交易日 | `5` |
| 止损比例 | 可选，如 0.05 表示亏损 5% 强制卖出 | `0`（不启用） |
| 止盈比例 | 可选，如 0.10 表示盈利 10% 强制卖出 | `0`（不启用） |
| 使用复权 | 是否使用前复权数据 | ✅ 推荐开启 |

**输出结果：**

- **买入/卖出价**：信号日收盘价与离场日收盘价
- **持有天数**：实际持有交易日数量
- **总收益率**：持有期间总收益率（小数，如 0.05 = 5%）
- **最大回撤**：持有期间从峰值到谷值的最大亏损幅度
- **是否盈利**：绿色表示盈利，红色表示亏损
- **沪深 300 基准**：同期持有沪深 300 的收益率
- **超额收益（Alpha）**：个股收益率 − 基准收益率

> ⚠️ 历史回测收益不代表未来表现，仅供学习研究参考。

### 2.3 批量回测

对一个股票在指定日期范围内，每日信号都执行一次回测，聚合统计。

| 参数 | 说明 |
|------|------|
| 股票代码 | A 股代码 |
| 开始日期 | 回测区间起点 |
| 结束日期 | 回测区间终点 |
| K 线周期 | 日线 / 周线 / 月线 |
| 复权方式 | 前复权 / 不复权 |
| 买入价格 | 0 用每日收盘价 |
| 持有天数 | 每笔交易持有 N 日 |
| 止损/止盈 | 同上 |

**输出聚合统计：**

- **总交易次数**：区间内共执行了多少次买入
- **胜率**：盈利交易占比
- **平均收益率**：所有交易的平均回报
- **最大回撤**：区间内组合的最大资金回撤
- **夏普比率**：风险调整后收益（年化）
- **累计收益率**：区间总收益
- **胜率（按季度/年份）**：时间维度分组胜率

## 3. 数据管理

### 3.1 入口

点击左侧导航菜单 **「数据管理」**（图标：⚙️），进入数据管理页面。

### 3.2 K-Line 缓存统计

页面左上角展示 SQLite 中缓存的 K 线数据概览：

| 指标 | 说明 |
|------|------|
| Total Bars | 缓存的总 K 线条数 |
| Unique Stocks | 已缓存数据的股票数量 |
| Date Range | 缓存数据的时间范围 |
| Last Sync | 最近一次同步时间 |

数据说明：

- K 线数据存储在本地 SQLite 数据库的 `kline_bars` 表
- 按 `(股票代码, 周期, 交易日期, 是否复权)` 唯一索引，自动去重
- 缓存数据用于回测引擎离线计算，避免重复拉取 API

### 3.3 历史数据同步

#### 启动同步

点击 **「启动历史数据同步」** 按钮，程序将：

1. 从 `all_stock_info` 表读取全部 A 股代码列表（SH/SZ 开头）
2. 为每只股票创建同步任务（默认最近 5 年日线）
3. 异步执行数据拉取与写入

#### 查看进度

点击 **「刷新进度」** 按钮查看同步状态表格：

| 列 | 说明 |
|----|------|
| 股票代码 | 正在同步的股票 |
| 周期 | K 线周期 |
| 状态 | `pending` 等待 / `running` 运行中 / `done` 完成 / `error` 失败 |
| 错误信息 | 失败时的原因 |

> 💡 提示：全市场 5000+ 只股票的完整同步需要较长时间，程序会断点续传——中断后重新启动同步会自动跳过已完成任务。

### 3.4 数据种子脚本

对于需要完整历史数据的场景，项目提供独立的 Python 种子脚本：

```bash
# 安装依赖
pip install baostock pandas

# 运行种子脚本（需在 Python 环境中）
python scripts/history_seed/baostock_seed.py --start 20190101 --output ./history_seed/
```

> 首次运行 go-stock 后，数据库初始化完成，再执行种子脚本即可批量导入全量历史数据。日常增量更新走内置的腾讯/东方财富/免费数据源，无需再次运行 Python 脚本。

## 4. 常见问题

### 4.1 回测结果为空

- 确认股票代码格式正确（如 `sh600519`、`sz000001`）
- 确认信号日期在 K 线数据覆盖范围内
- 检查数据管理页是否有缓存数据，尝试先启动历史数据同步

### 4.2 回测收益率异常（过高/过低）

- 检查是否开启了「使用复权」——不复权数据会因分红送股产生跳空
- A 股 T+1 规则已内置：信号日买入，最早次一交易日卖出
- 涨停/跌停日无法成交，引擎会标记滑点警告

### 4.3 同步进度长时间无变化

- 数据源有频率限制，每只股票请求间隔约 1 秒
- 5000+ 只股票预计耗时 1-2 小时
- 关闭程序后重新启动同步可断点续传

### 4.4 是否需要付费 API

不需要。回测与数据缓存完全基于免费数据源（腾讯财经、东方财富、免费 TCP 接口），所有数据存储在本地 SQLite，无需任何付费订阅。

## 5. 技术说明

### 5.1 回测引擎规则

| 规则 | 实现方式 |
|------|----------|
| T+1 结算 | 信号日收盘价买入，T+N 日收盘价卖出 |
| 涨跌停限制 | 买入日涨停/卖出日跌停标记滑点警告 |
| 前复权 | 使用 qfq 数据保证收益连续 |
| 交易单位 | 100 股（1 手）整数倍 |
| 基准对比 | 同期沪深 300 收益率计算 Alpha |

### 5.2 数据存储

| 表名 | 用途 |
|------|------|
| `kline_bars` | K 线数据持久化（按 股票+周期+日期+复权 唯一） |
| `kline_sync_log` | 每只股票的同步状态与进度 |
| `ai_recommend_backtests` | AI 推荐回测结果记录 |
| `datasource_cache` | 现有通用 KV 缓存（非时间序列数据） |

### 5.3 数据源优先级

| 优先级 | 来源 | 用途 |
|--------|------|------|
| 1 | mootdx/TDX | 日线前复权（TCP，不封 IP，量大首选） |
| 2 | 腾讯财经 | 日线前复权（HTTP，备用） |
| 3 | 东方财富 | 日线前复权（HTTP，有限速） |
