### 1.2 核心抽象层（已具备扩展能力）

go-stock 已在 `backend/data/datasource/` 中构建了**数据源路由层 (Router)**，支持：

- **多 Provider 注册**：QuoteProvider / KLineProvider / NewsProvider / FundamentalProvider / SectorProvider
- **优先级排序**：按 Priority() 排序，高优先级优先尝试
- **自动降级 (Fallback)**：主源失败自动切换到备用源
- **缓存层 (CacheLayer)**：减少重复请求，支持 TTL
- **K线持久化 (KLineStore)**：SQLite 本地存储历史K线

## 二、全球金融数据接入方案

### 2.1 方案总览

基于 go-stock 已有的 datasource Router 架构，推荐通过 **"新增 Provider 实现接口 + 注册到 Router"** 的方式接入全球数据：

| 数据类别 | 推荐数据源 | 覆盖市场 | 接入方式 |
|---------|-----------|---------|---------|
| 全球股票实时行情 | **Alpha Vantage** / **Twelve Data** / **Finnhub** | 全球 60+ 交易所 | REST API |
| 全球股票 K线 | **Yahoo Finance** (已有) / **Alpha Vantage** | 全球 | REST API |
| 外汇 (Forex) | ** exchangerate.host** / **Open Exchange Rates** / **Alpha Vantage** | 全球 170+ 货币对 | REST API |
| 加密货币 | **CoinGecko** / **CoinMarketCap** | BTC/ETH/主流币 | REST API |
| 全球指数 K线 | **Yahoo Finance** / **Alpha Vantage** | 标普/纳指/恒指/日经等 | REST API |
| 商品期货 | **Yahoo Finance** (已有) | 黄金/白银/原油 | REST API |
| 宏观经济 | **World Bank Open Data** / **IMF WEO** | GDP/CPI/利率/失业率 | REST API |
| 债券/利率 | **FRED (美联储)** / **Trading Economics** | 美债收益率/全球利率 | REST API |

// normalizeAlphaVantageSymbol 将 go-stock 内部代码转换为各数据源格式
func normalizeAlphaVantageSymbol(code string) string {
    // go-stock 内部格式: "usAAPL" / "hk00700" / "sh600519"
    // Alpha Vantage 格式: "AAPL" / "0700.HK" / "600519.SHH"
    switch {
    case strings.HasPrefix(code, "us") || strings.HasPrefix(code, "gb_"):
        return strings.TrimPrefix(strings.TrimPrefix(code, "us"), "gb_")
    case strings.HasPrefix(code, "hk"):
        return strings.TrimPrefix(code, "hk") + ".HK"
    case strings.HasPrefix(code, "sh"):
        return strings.TrimPrefix(code, "sh") + ".SS"  // 上交所
    case strings.HasPrefix(code, "sz"):
        return strings.TrimPrefix(code, "sz") + ".SZ"  // 深交所
    default:
        return code
    }
}

func normalizeTwelveDataSymbol(code string) string {
    // Twelve Data 格式: "AAPL" / "0700:HK" / "600519:SH"
    switch {
    case strings.HasPrefix(code, "us") || strings.HasPrefix(code, "gb_"):
        return strings.TrimPrefix(strings.TrimPrefix(code, "us"), "gb_")
    case strings.HasPrefix(code, "hk"):
        return strings.TrimPrefix(code, "hk") + ":HK"
    case strings.HasPrefix(code, "sh"):
        return strings.TrimPrefix(code, "sh") + ":SH"
    case strings.HasPrefix(code, "sz"):
        return strings.TrimPrefix(code, "sz") + ":SZ"
    default:
        return code
    }
}

### 2.3 Provider 注册到 Router

在应用初始化时（如 `app.go` 或 `app_lifecycle.go`），注册新 Provider：

```go
// backend/app.go (或专门的初始化函数)
import "go-stock/backend/data/datasource"

func initDataSourceRouter(config *data.SettingConfig) {
    router := datasource.GetRouter()
    
    // 1. 注册 Twelve Data Provider（高优先级，全球覆盖好）
    if config.TwelveDataApiKey != "" {
        td := datasource.NewTwelveDataProvider(config.TwelveDataApiKey)
        router.RegisterQuoteProvider(td)
        router.RegisterKLineProvider(td)
    }
    
    // 2. 注册 Alpha Vantage Provider（中优先级，备用）
    if config.AlphaVantageApiKey != "" {
        av := datasource.NewAlphaVantageProvider(config.AlphaVantageApiKey)
        router.RegisterQuoteProvider(av)
        router.RegisterKLineProvider(av)
        router.RegisterFundamentalProvider(av) // Alpha Vantage 有基本面数据
    }
    
    // 3. 注册 CoinGecko Provider（加密货币）
    cg := datasource.NewCoinGeckoProvider()
    router.RegisterQuoteProvider(cg)
    router.RegisterKLineProvider(cg)
    
    // 4. 设置缓存层（已有的 freecache）
    cache := datasource.NewCacheLayer(/* ... */)
    router.SetCache(cache)
}
```

## 七、代码示例：完整的全球指数 K线 Provider

```go
// backend/data/datasource/global_index_provider.go
package datasource

import (
    "context"
    "encoding/json"
    "fmt"
    "time"
    "github.com/go-resty/resty/v2"
)

// GlobalIndexProvider 通过 Yahoo Finance 获取全球指数K线
// 支持: 标普500(^GSPC), 纳斯达克(^IXIC), 道琼斯(^DJI), 
//       恒生(^HSI), 日经225(^N225), 英国富时100(^FTSE),
//       德国DAX(^GDAXI), 法国CAC40(^FCHI)
type GlobalIndexProvider struct {
    client *resty.Client
}

func NewGlobalIndexProvider() *GlobalIndexProvider {
    return &GlobalIndexProvider{
        client: resty.New().SetTimeout(10 * time.Second),
    }
}

func (p *GlobalIndexProvider) Name() string  { return "yahoo-global-index" }
func (p *GlobalIndexProvider) Priority() int { return 5 }
func (p *GlobalIndexProvider) Available(ctx context.Context) bool {
    return true // Yahoo Finance 无需 Key
}

func (p *GlobalIndexProvider) GetKLine(ctx context.Context, code, period string, count int) (*KLineData, error) {
    // 将 go-stock 代码转换为 Yahoo Finance 格式
    symbol := mapYahooIndexSymbol(code)
    if symbol == "" {
        return nil, fmt.Errorf("unsupported global index: %s", code)
    }
    
    interval := "1d"
    rangeParam := yahooRangeForCount(count, period)
    
    url := fmt.Sprintf("https://query1.finance.yahoo.com/v8/finance/chart/%s?interval=%s&range=%s",
        symbol, interval, rangeParam)
    
    resp, err := p.client.R().
        SetHeader("User-Agent", "Mozilla/5.0").
        Get(url)
    if err != nil {
        return nil, err
    }
    
    bars, err := parseYahooKLine(resp.Body(), code)
    if err != nil {
        return nil, err
    }
    
    return &KLineData{Bars: bars}, nil
}

func mapYahooIndexSymbol(code string) string {
    switch code {
    case "us_SPX":   return "%5EGSPC"   // 标普500
    case "us_NDX":   return "%5EIXIC"   // 纳斯达克
    case "us_DJI":   return "%5EDJI"    // 道琼斯
    case "hk_HSI":   return "%5EHSI"    // 恒生
    case "jp_N225":  return "%5EN225"   // 日经225
    case "uk_FTSE":  return "%5EFTSE"   // 富时100
    case "de_DAX":   return "%5EGDAXI"  // DAX
    case "fr_CAC":   return "%5EFCHI"   // CAC40
    default:
        return ""
    }
}
```

2. **注册到 Router**：在应用初始化时按优先级注册，利用已有的自动降级和缓存能力。
3. **扩展配置**：在 Settings 中新增 API Key 字段，前端添加配置界面。
4. **前端调用**：通过 Wails Handler 暴露给 Vue 前端，保持与现有 API 风格一致。
5. **AI 增强**：将全球数据工具函数注册到 AI Agent，实现跨市场智能分析。
