## 1. 软件简介

go-stock 是一款基于大语言模型的 AI 赋能股票分析桌面工具，基于 **Wails + Vue3 + NaiveUI** 技术栈构建，支持 A股、港股、美股的行情数据获取与智能分析。

### 1.1 核心特性

- 多市场行情监控（A股/港股/美股）
- AI 智能分析股票（支持 16 个大模型平台）
- AI 智能体对话（React/PlanExecute 两种模式）
- 浮动 AI 助手（任意页面快速唤起对话）
- 实时 K 线图与分时图（ECharts + TradingView Lightweight Charts）
- 市场资讯聚合（财联社/新浪/外媒/雪球）
- 资金流向与龙虎榜数据
- 涨停梯队与异动监控
- 社区化提示词广场与问答广场
- MCP 服务与技能扩展（含技能追踪/评分/推荐/URL生成）
- 定时任务与自动预警（5种预警类型）
- 交易日志管理（Beta）
- 弹幕互动社区
- 钉钉推送与本地通知
- **每日选股**：多因子评分模型自动筛选优质股票
- **回测验证**：策略历史回测，验证选股模型有效性
- **K线分析**：多周期多指标技术分析
- **数据管理**：基础数据维护与管理

### 1.2 支持的 AI 模型平台

DeepSeek、硅基流动、智谱AI、字节豆包、阿里云百炼、Moonshot、腾讯混元、讯飞星火、零一万物、MiniMax、百川智能、百度千帆、OpenAI、Azure OpenAI、OpenRouter、Ollama 以及所有兼容 OpenAI API 格式的平台。

### 1.3 数据来源

| 数据来源 | 用途 |
|----------|------|
| 东方财富 | 行情数据、资金流向、财报数据、龙虎榜、K线 |
| 同花顺问财 | 自然语言选股、行情查询、研报搜索 |
| 新浪财经 | 财经新闻、基金数据 |
| 财联社 | 实时市场电报快讯 |
| 雪球 | 热门事件、股票讨论 |
| 华尔街见闻 | 外媒资讯、市场日历 |
| TradingView | 国外财经媒体、K线数据 |

## 2. 安装与启动

### 2.1 下载软件

从 GitHub Releases 页面下载对应版本的安装包：

- Windows 版：`go-stock-windows-amd64.exe`
- macOS 版：`go-stock-darwin-universal`

### 2.2 首次启动

1. 双击运行程序
2. 首次启动会自动初始化股票基础数据（A 股/港股/美股基础信息）
3. 窗口大小会自适应屏幕分辨率
4. 加载完成后进入主界面

### 2.3 数据存储

- 数据库文件：运行目录下 `data/stock.db`（SQLite）
- 字典数据：运行目录下 `data/` 目录
- 配置信息保存在本地数据库中

## 3. 界面布局与导航菜单

### 3.1 整体布局

软件采用**底部水平导航栏 + 上方内容区**的布局方式，导航菜单固定在窗口底部。

### 3.2 导航菜单结构

| 菜单项 | 路由 | 说明 |
|--------|------|------|
| ⭐ 股票自选 | `/` | 自选股管理，含分组子菜单 |
| 📰 市场行情 | `/market` | 市场数据与资讯，含11个子菜单 |
| ✨ 基金自选 | `/fund` | 基金关注与管理（需启用） |
| 🤖 AI智能体 | `/agent` | AI智能体对话（需启用） |
| 🔬 K线分析 | `/kline-analysis` | 多指标多周期技术面分析 |
| 🔬 回测验证 | `/backtest` | 策略历史回测 |
| 🔬 每日选股 | `/daily-pick` | 多因子量化选股 |
| 🔬 研究中心 | `/research` | 研究分析工具集，含13个子菜单 |
| 🔬 数据管理 | `/data-manager` | 基础数据维护 |
| ⚙️ 设置 | `/settings` | 软件配置 |
| 隐藏至托盘区 | — | 最小化到系统托盘 |
| 退出程序 | — | 关闭应用 |

> ⚠️ 注意：「基金自选」和「AI智能体」两个菜单项需要在后台配置中启用对应功能后才会显示。

### 3.3 窗口标题栏

标题栏动态显示当前市场状态，格式为：

```
go-stock A股交易中|港股休市|美股休市  「投资格言」  [数据来源于网络，仅供参考；投资有风险，入市需谨慎]
```

市场状态每 60 秒自动刷新，同时随机切换一条投资格言。

### 3.4 滚动快讯条

当在设置中启用"显示滚动快讯"后，页面顶部会以跑马灯形式滚动显示市场快讯标签。

### 3.5 水印

软件界面叠加有水印层，用于数据来源声明和防伪标识。

## 4. 股票自选

股票自选是软件的核心页面，用于管理和监控关注的股票。

### 4.1 标签页分组

页面顶部为标签页栏，支持分组管理自选股：

| 操作 | 说明 |
|------|------|
| 点击"全部" | 查看所有自选股 |
| 点击分组标签 | 查看该分组内的股票 |
| 点击"+"按钮 | 新增分组（输入分组名称和排序值） |
| 点击标签关闭按钮 | 删除分组（需二次确认，数据不可恢复） |
| 拖拽标签 | 调整分组排序（"全部"标签不可拖拽） |

分组列表会在启动时从数据库动态加载，每个分组作为"股票自选"菜单的子菜单项显示。

### 4.2 自选股卡片

每只自选股以卡片形式展示，包含以下信息区域：

#### 卡片标题区

- **股票代码标签**：显示股票代码
- **取消关注**按钮：移除该股票
- **AI分析**按钮：发起 AI 智能分析（需启用 AI 功能）
- **移出分组**按钮：将股票从当前分组移出（仅在分组标签下显示）

#### 价格信息区

- **当前价格**：实时价格，涨为红色，跌为绿色，平为默认色
- **盘前盘后价格**：仅美股显示盘前盘后价格及涨跌幅
- **涨跌幅百分比**：带数字动画效果
- **今日盈亏金额**：仅在设置了成本价和持仓数量后显示
- **迷你走势线**：仅在分组标签下显示

#### 行情数据区

四宫格显示：最高价+最高涨幅百分比、最低价+最低跌幅百分比、昨日收盘价、今日开盘价

#### 盘口数据区（仅A股）

可折叠面板，展示买卖五档盘口数据。折叠时显示买一报价(申报量)/卖一报价(申报量)，展开后显示买一至买五、卖一至卖五各档的报价和申报量。

#### 卡片底部

- 日期和时间
- 持股数量标签（设置持仓后显示）
- 成本盈亏标签："成本:xxx*xxx 盈亏% (xxx ¥)"
- **多周期K线**按钮

#### 卡片操作按钮

| 按钮 | 功能 |
|------|------|
| 成本 | 打开成本设置对话框 |
| 分时 | 打开分时走势图 |
| 日K | 打开日 K 线图 |
| 资金 | 打开资金趋势图（仅A股显示） |
| 详情 | 跳转问财搜索页面 |
| 公告 | 跳转公司公告页面（仅A股） |
| 研报 | 跳转个股研报页面（仅A股） |
| 设置分组 | 下拉菜单，将股票添加到指定分组 |

### 4.3 底部搜索栏

位于页面右下角，包含：

- **自动完成输入框**：输入股票名称/代码/指数关键词，实时模糊匹配
- **关注**按钮：将搜索到的股票添加到自选列表
- **发送弹幕**按钮（需启用弹幕功能）：通过 WebSocket 发送弹幕消息

> 💡 提示：搜索已关注的股票时，页面会自动滚动到对应卡片并闪烁红色边框5秒。

### 4.4 成本设置对话框

点击"成本"按钮打开，宽度800px，表单字段：

| 字段 | 说明 |
|------|------|
| 股票成本 | 成本价，支持 HK$/¥ 后缀自动适配 |
| 股票数量 | 持仓数量，步进100 |
| 涨跌提醒 | 涨跌幅预警百分比 |
| 股价提醒 | 绝对价格预警 |
| 开仓价 | 开仓价位 |
| 股票排序 | 排序值 |
| 止盈价 | 止盈价格 |
| 止损价 | 止损价格 |

### 4.5 分时图对话框

点击"分时"按钮打开，宽度1000px：

- 使用 ECharts 绘制当日分时走势图
- 包含股价线和成交量柱状图
- 标记最高/最低价位点
- 标记均价线、开盘价线、收盘价线
- 低于开盘价（绿色）、大于开盘价小于收盘价（蓝色）、大于收盘价（红色）分段着色
- **自动刷新**：打开后每 10 秒自动刷新

### 4.6 日K线图对话框

点击"日K"按钮打开，宽度1000px：

- 日K蜡烛图
- MA5/MA10/MA20/MA30 均线
- 成交量柱状图
- 数据缩放滑块，默认显示近14%的数据
- 标记最高/最低/平均收盘价
- 鼠标悬停提示框（开盘/收盘/最低/最高/成交量/各均线值）
- 数据来源：近365天K线数据

### 4.7 AI分析对话框

点击"AI分析"按钮打开，宽度800px：

- Markdown 格式渲染 AI 分析结果，加载状态旋转动画，导出 PDF 工具栏
- 底部信息：模型名称标签 + 分析时间 + 风险提示
- 工具调用开关 / 思考模式开关
- 三个下拉选择框：AI 模型服务配置、系统提示词、用户提示词
- 问题输入框：自定义提问内容

| 按钮 | 功能 |
|------|------|
| 开始AI分析 | 重新发起 AI 流式分析 |
| 保存为图片 | 截图保存为 PNG |
| 复制到剪切板 | 复制分析结果文本 |
| 保存为Markdown | 保存为 `.md` 文件 |
| 保存为Word | 导出为 `.docx` 文件 |
| 分享到项目社区 | 分享到社区 |

### 4.8 资金趋势对话框

点击"资金"按钮打开，宽度1000px，使用 MoneyTrend 组件展示近 360 天资金趋势图，图表高度 500px。

### 4.9 多周期K线对话框

点击"多周期K线"按钮打开，最大宽度 1100px：

- 使用轻量级 K 线图组件（TradingView Lightweight Charts）
- 支持拖拽调整开仓价/止损价/止盈价/成本价线，调整后自动保存

> ⚠️ 注意：VIP权限控制：VIP2 及以上用户可正常使用，权限不足时提示并自动关闭。美股代码（`gb_` 前缀）不支持多周期K线。

### 4.10 价位线预警系统

每次价格更新时自动检查：

| 预警类型 | 触发条件 | 推送类型 |
|----------|----------|----------|
| 涨跌幅预警 | 涨跌幅达到设定百分比 | 类型1 |
| 股价预警 | 股价触及设定价格 | 类型2 |
| 成本价预警 | 成本盈亏达到设定值 | 类型3 |
| 止盈触及 | 当前价 ≥ 止盈价 | 类型4 |
| 止损触及 | 当前价 ≤ 止损价 | 类型5 |

防抖机制：同一价格不重复提醒，两次通知间隔至少60秒。

### 4.11 弹幕系统

- 连接 WebSocket 服务器实时接收弹幕
- 使用 vue3-danmaku 组件展示弹幕飘过效果
- 可在设置中开启/关闭弹幕功能

|------|-------------|

- AI 回复以流式方式逐字展示

- 自动检测内容中的 JSON 并提取为"分析报告"
- 每 1.5 秒定时格式化 Markdown

### 7.6 PlanExecute 模式详解

PlanExecute 模式采用 Planner→Executor→Replanner 管道，最大迭代7次。AI 首先制定分析计划，然后逐步执行每个步骤，执行完成后重新评估是否需要调整计划。系统对执行结果进行智能压缩：最近步骤获得更多预算，较早步骤预算减少，确保关键信息不丢失。

### 7.7 其他交互

- **回到底部**：悬浮按钮，滚动时自动出现
- **停止生成**：中断 AI 回复
- **复制操作**：复制消息内容
- **暗黑主题**：自动跟随系统配置

#### 9.8.1 参数说明

形态选股的筛选条件分为 3 大类：

**1. 技术指标信号（多选，可叠加）**

| 信号 | 说明 | 适用场景 |
|------|------|----------|
| MACD 金叉 | DIF 线上穿 DEA 线，短期趋势转强 | 趋势启动初期介入 |
| KDJ 金叉 | K 线上穿 D 线，超卖区金叉更有效 | 短线反弹捕捉 |
| 向上突破 5 日均线 | 收盘价上穿 MA5，短期走强 | 短线趋势跟随 |
| 均线多头排列 | MA5 > MA10 > MA20 且均向上 | 中线趋势确认 |
| 均线空头排列 | MA5 < MA10 < MA20 且均向下 | 规避下跌趋势股 |
| 突破（带量） | 放量突破关键阻力位 | 追涨启动点 |
| 连涨放量 | 连续上涨且量能持续放大 | 趋势中段加仓 |
| 缩量下跌 | 下跌中成交量逐步萎缩 | 寻找止跌企稳 |
| 一字板 / 两阳夹一阴 | K 线组合形态 | 强势股识别 |

**2. K 线形态（多选）**

| 形态 | 含义 |
|------|------|
| 早晨之星 / 曙光初现 | 底部反转信号 |
| 黄昏之星 / 乌云盖顶 | 顶部反转信号 |
| 锤头线 / 倒锤头 | 底部止跌信号 |
| 射击之星 / 吞没形态 | 顶部见顶信号 |
| 十字星 / 身怀六甲 | 趋势可能反转的预警 |
| 孕线 | 短期可能选择方向 |

**3. 连续天数筛选（单选）**

- **连涨天数**：3 / 5 / 8 天及以上，筛出连续上涨的强势股
- **连跌天数**：3 / 5 / 8 / 10 / 14 天及以上，筛出超跌反弹候选
- **人气排名连涨**：3 / 5 / 7 天，筛出市场关注度持续上升的股票

#### 9.8.2 使用建议

| 你的场景 | 推荐组合 |
|----------|----------|
| **短线追涨（3-5 天）** | 向上突破 5 日均线 + 连涨放量 + 缩量回调，技术面强势但未过度炒作 |
| **捕捉启动点** | 均线多头排列 + MACD 金叉 + 突破（带量），趋势刚形成、量能配合 |
| **超跌反弹** | 连跌 8-14 天 + 早晨之星 / 锤头线 + 低位资金净流入（结合其他页签） |
| **规避下跌趋势** | 均线空头排列 + 乌云盖顶 / 黄昏之星，跳过这类股不接飞刀 |
| **打板/强势股** | 一字板 / 两阳夹一阴 + 连涨放量 + 涨停梯队（结合其他页签） |
| **埋伏热门题材** | 人气排名连涨 5-7 天 + 所属行业 / 所属概念（结合题材热度） |

> 💡 **叠加使用**：勾选越多条件结果越少也越精准，但过度叠加可能漏掉优质股。建议从 2-3 个核心条件起步，逐步增加。

> ⚠️ **单日筛选的局限**：形态选股反映的是"当下某一天"满足条件的股票，不等于未来会涨。务必结合 §11 每日选股的综合评分、§13 回测验证的历史表现共同决策。

## 11. 每日选股

每日选股页面是一个多因子量化选股工具，基于技术指标对全市场 A 股进行综合评分，每日自动筛选优质标的。

### 11.1 选股评分模型

综合评分由 6 个因子加权计算（总分 100）：

| 因子 | 权重 | 说明 |
|------|------|------|
| 量比因子（VolumeFactor） | 0.20 | 当日成交量与近期均量的比值，衡量放量程度 |
| 均线因子（MAFactor） | 0.20 | 收盘价相对 MA5/MA10/MA20 的位置，衡量趋势强度 |
| RSI因子 | 0.15 | 14日相对强弱指标，<30 为超卖加分 |
| MACD因子 | 0.15 | MACD 柱值反映动能方向 |
| 价格因子 | 0.15 | 当日涨跌幅衡量价格强度 |
| 换手率因子（TurnoverFactor） | 0.15 | 换手率 3-10% 为理想区间，过低缺乏活性过高有出货风险 |

### 11.2 界面与操作

- **运行选股**：点击"运行选股"按钮，系统基于所选日期执行全市场扫描，返回评分最高的前 N 只股票
- **日期选择**：支持选择历史日期，用于回溯验证（回测场景）
- **选股结果表格**：

  | 列 | 说明 |
  |----|------|
  | 排名/日期/代码/名称 | 基础信息 |
  | 综合评分 | 6 因子加权总分，≥70 绿色，≥50 黄色，<50 灰色 |
  | 收盘价/涨跌幅 | 当日价格数据 |
  | MA5/10/20 | 三条均线值 |
  | RSI/MACD | 技术指标值 |
  | 量比因子/均线因子 | 因子分解得分 |
  | 次日收益 | 次日实际涨跌幅（需复盘后显示），红色涨/绿色跌 |
  | 最大收益/最大回撤 | 持仓期间表现（需复盘后显示） |
  | 选股理由 | 系统生成的因子分析说明 |
  | 备注 | 用户自定义备注，点击可编辑 |

- **复盘**：点击"复盘"按钮，系统拉取已选股票的后续 K 线数据，计算次日收益、最大收益、最大回撤，标记涨跌状态
- **统计面板**：顶部显示选股总数、已复盘数、胜率、平均收益率、最大收益率、最大回撤等汇总指标
- **备注编辑**：点击表格备注列，弹窗输入自定义备注内容

- 代码格式自动处理（`.SH`/`.SZ` 后缀兼容）

## 13. 回测验证

回测验证页面用于对选股信号和交易策略进行历史数据回测，验证策略有效性。

> 💡 **股票代码搜索**：单次/批量/参数优化 3 个页签的股票代码输入框共享同一份过滤逻辑。
> - **输入 ≥ 2 个字符**才会显示匹配下拉项（避免一次性展示全市场 5000+ 只股票）
> - 匹配范围：股票**名称**（如「平安」）或**代码**（如「000001」）包含输入内容
> - 输入框聚焦但未输入时，**下拉框保持关闭**，不显示任何选项
> - 支持选中后回填股票代码，最多展示 100 条匹配项

### 13.1 单次回测

#### 13.1.1 参数说明

| 参数 | 说明 | 取值建议 |
|------|------|----------|
| 股票代码 | 目标股票，输入名称或代码 ≥2 字符触发自动补全下拉 | 6 位代码或带后缀（如 `000001.SZ`） |
| 信号日期 | 买入信号的日期，决定回测起点 | 选历史交易日，避免停牌/数据缺失 |
| 买入价格 | 建仓价格 | `0` = 信号日收盘价（推荐，反映真实可成交价）；非 0 = 限价单测试 |
| 持有天数 | 持仓周期（交易日） | 短线 3-10 / 波段 10-30 / 中线 30-60；超过 K 线数据范围会报错 |
| 止损比例 | 下跌触发止损的百分比 | 短线 3-5% / 波段 5-8% / 中线 8-12%；激进可放宽 |
| 止盈比例 | 上涨触发止盈的百分比 | 通常为止损的 2-3 倍（盈亏比 ≥ 2:1） |
| 复权处理 | 开关，启用时使用前复权价格 | 长期回测建议开启，避免除权除息造成价格断层 |

**回测结果**：展示收益曲线、持有期涨跌幅、最大收益、最大回撤、买卖点标记。

#### 13.1.2 回测原理（核心机制）

理解回测如何运作，才能正确解读结果：

1. **T+1 约束**：信号日（bars[0]）为买入日，从下一交易日开始检查卖出条件。**买入当日不可卖出**，符合 A 股实际交易规则。
2. **涨跌停禁入**：信号日若股票涨停（主板 ≥ 10%、创业板/科创板 ≥ 20%、北交所 ≥ 30%、ST 股 5%），回测直接报错——因为涨停无法买入。
3. **止损止盈触发**：
   - 每日先检查**最低价**是否触及止损线（`entry × (1 - stopLoss)`）
   - 再检查**最高价**是否触及止盈线（`entry × (1 + stopProfit)`）
   - 同一天两个条件都满足时，**止损优先**（保守估计）
   - 触发后以触发价成交（假设能成交）
4. **最大回撤**：从买入后到出场期间，股价相对最高点的最大回落幅度
5. **基准对比**：默认对比 `sh510300`（沪深 300 ETF），计算 Alpha = 策略收益 - 基准收益
6. **涨跌停警告**：若买入日接近涨停（收盘 ≥ 最高价 × 99.9%）或卖出日接近跌停，结果中会显示 `SlippageWarning`，提示实际成交可能滑点

> 💡 **典型工作流**：
> 1. 在「每日选股」跑出某天 Top10 候选 → 记录股票代码
> 2. 在「回测验证 → 单次回测」逐只输入代码，把信号日期设为选股当天
> 3. 用统一参数（止损 5% / 止盈 15% / 持有 10 天）回测，**横向对比**这 10 只的胜率和平均收益
> 4. 对胜率高的几只，再用「参数优化」找出最佳止损/止盈/持有天数

### 13.2 批量回测

| 参数 | 说明 |

### 13.4 策略回测

**结果展示**：

> 💡 典型用法：在「每日选股」页面跑出某天的选股结果后，切换到「策略回测」页签，把信号日期设为该天，回看这些股票在后续若干交易日的实际表现。

### 13.5 历史记录

查询并回看所有已完成的回测任务结果（单次回测 + 批量回测 + 策略回测 + 参数优化 自动持久化）。

| 操作 | 说明 |
|------|------|
| 股票代码筛选 | 顶部输入框输入 6 位股票代码精确筛选，留空=全部 |
| 查询按钮 | 触发当前筛选条件下的分页查询 |
| 分页控制 | 支持 10/15/30/50 条/页切换 |
| 虚拟滚动 | 数据量大时自动启用，流畅展示上千行 |

**结果列**：股票代码、股票名称、信号日期、入场价格、出场价格、总收益率（带颜色）、持仓天数、最大回撤、Alpha、盈亏标记。

### 13.6 参数优化

对单只股票在指定时间区间内，遍历多组风控参数（持仓天数/止损/止盈），按综合评分排序，找出最佳参数组合。

| 区域 | 字段 | 说明 |
|------|------|------|
| 基础设置 | 股票代码 | 输入名称或代码 ≥2 字符触发自动补全 |
| 基础设置 | 开始/结束日期 | 回测时间区间 |
| 基础设置 | 前复权 | 是否使用前复权价格 |
| 参数搜索空间 | 持仓天数 | 多个候选值，逗号分隔，如 `5,10,20,40,60` |
| 参数搜索空间 | 止损范围 | 多个候选值，逗号分隔，如 `0.03,0.05,0.08,0.12` |
| 参数搜索空间 | 止盈范围 | 多个候选值，逗号分隔，如 `0.10,0.15,0.20,0.30` |
| 目标函数权重 | 夏普权重 | 综合评分中夏普比率的占比（0~1） |
| 目标函数权重 | 胜率权重 | 综合评分中胜率的占比（0~1） |
| 目标函数权重 | 收益权重 | 综合评分中总收益率的占比（0~1） |
| 目标函数权重 | 回撤惩罚 | 综合评分中对最大回撤的惩罚项（0~1） |
| 输出 | 返回 TopN | 返回评分最高的前 N 组参数组合 |

> ⚠️ **组合数上限 256**：三个参数列表长度的乘积超过 256 时系统会拒绝执行，避免计算时间过长。可通过减少候选值数量或调高 TopN 阈值来控制。

> 💡 **预设按钮**：保守 / 均衡 / 激进 三个预设可一键填充常用的参数搜索空间，免去手动输入。

**结果展示**：表格按综合评分降序，列出每组参数的具体取值、对应的胜率、均收益、夏普、最大回撤、回测数。

### 17.2 AI Agent 架构

基于 cloudwego eino 框架构建。提供两种 Agent 实现：

- **React Agent**：简单查询模式，单步工具调用，包含错误恢复和未知工具处理中间件，以及智能内容压缩（优先级：标题 > 摘要 > 数据 > 其他）
- **PlanExecute Agent**：复杂分析模式，Planner→Executor→Replanner 管道，最大7次迭代，分级压缩执行结果

### 17.3 MCP 与技能扩展

**MCP（Model Context Protocol）**：在研究中心添加 MCP 服务器配置后，AI 智能体运行时自动通过 `getMCPTools()` 动态加载外部工具。支持添加任意兼容 MCP 协议的服务器，配置 URL 和认证信息后即可启用。

**技能系统**：通过技能管理器创建自定义技能，配置触发关键词和绑定MCP服务。AI 智能体运行时通过 `buildSkillPrompt()` 检测提问内容是否匹配技能触发关键词，匹配则注入技能系统提示词。技能分类包括：股票分析、技术分析、基本面分析、量化策略、风险管理、资讯研究、通用。

**技能分析系统（新增）**：

- **使用追踪（Usage Tracker）**：每次 AI 调用自动记录触发的技能、执行耗时、token 消耗、成功/失败状态，写入 `skill_usage_records` 表
- **评分引擎（Skill Scorer）**：按使用频率、平均评分、成功率、置信度、版本等多维度加权评分，支持定期重算
- **推荐器（Skill Recommender）**：根据用户提问内容进行关键词匹配和语义匹配，推荐最合适的技能，同时检测技能覆盖缺口
- **URL 生成器（URL Generator）**：输入网页 URL，自动抓取页面内容并调用 AI 生成技能名称、描述、系统提示词、触发关键词、示例等完整技能定义
- **技能分析 UI**：在技能管理器的"技能分析"标签页中展示评分热力图、推荐面板和缺口检测结果
