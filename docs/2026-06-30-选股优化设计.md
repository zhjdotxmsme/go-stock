# 选股优化设计文档

## 概述

两项改动：① 研究中心形态选股免费化；② 行业/研报等基本面数据集成到 AI 荐股系统（作为量化因子和 LLM 上下文）。

---

## Part 1：研究中心形态选股免费化

### 背景

形态选股（`allStockList.vue`）目前对非 VIP 用户限制使用技术面筛选条件，仅能查看原始股票列表。移除所有 VIP 门槛，向全部用户开放。

### 改动范围

| 位置 | 改动 |
|------|------|
| `allStockList.vue:28-44` | 移除 `onMounted` 中的 VIP 等级初始化——不再校验 `isValidVip` |
| `allStockList.vue:261-263` | 移除 `loadStocks()` 中非 VIP 重置筛选条件的逻辑 |
| `allStockList.vue:289-293` | 移除 `handleCheckedChange()` 中的 VIP 弹窗和重置逻辑 |

### 影响分析

- 后端无变化，`GetAllStocks()` API 本身无 VIP 校验
- 其他模块（SelectStock.vue K 线图 VIP 限制等）本次不动

## Part 2：行业/研报集成到 AI 荐股

### 目标

将市场行情中的行业资金排名、个股研报、宏观数据集成到股票评分系统，并作为 AI 荐股的分析上下文，形成"技术面 + 基本面"综合评分。

### 整体架构

```
RunDailyPick()
  │
  ├─ 预取宏观数据 (GDP/CPI/PMI) ── 1 次调用
  ├─ 预取行业资金排名 ───────── 1 次调用
  │
  ├─ [for each candidate stock]
  │   ├─ 计算 6 个技术因子 (现有)
  │   ├─ 计算行业强度分  ← 新
  │   ├─ 计算研报热度分   ← 新
  │   │
  │   ├─ baseline 加权得分 (现有)
  │   ├─ 运行全部策略 (现有 5 + 新 3)
  │   └─ 取最高分作为最终得分
  │
  └─ 存储到 daily_picks (含新因子字段)
```

### 新增量化策略（3 个）

#### 1. 行业强度策略 (IndustryStrengthStrategy)

- **数据源**: `GetIndustryMoneyRankSina()` → 行业资金净流入排名
- **逻辑**: 先通过股票代码查所属行业，再取该行业的资金排名百分位
- **评分**:
  - 排名前 10% → 1.0
  - 前 30% → 0.7
  - 前 50% → 0.4
  - 后 50% → 0.2
- **文件**: `backend/data/strategy_industry.go`

#### 2. 研报热度策略 (ResearchReportStrategy)

- **数据源**: `StockResearchReport(stockCode, 30)` → 近 30 天研报数量
- **逻辑**: 研报数量反映机构关注度
- **评分**:
  - ≥ 10 篇 → 1.0
  - ≥ 5 篇 → 0.7
  - ≥ 2 篇 → 0.4
  - < 2 篇 → 0.1
- **文件**: `backend/data/strategy_research.go`

#### 3. 宏观环境策略 (MacroEnvironmentStrategy)

- **数据源**: `GetPMI()`, `GetCPI()`, `GetGDP()`（预取一次）
- **逻辑**: 整体市场环境分，所有候选股共享
- **评分**:
  - PMI > 50（扩张）→ +0.5
  - PMI > 52 → +0.8
  - CPI 在 1%-3%（温和通胀）→ +0.3
  - GDP 增速 > 5% → +0.2
- **文件**: `backend/data/strategy_macro.go`

### 数据结构扩展

#### StrategyContext 新增字段

```go
type StrategyContext struct {
    // ... 现有 K 线字段 ...

    IndustryCode      string  // 所属行业代码
    IndustryRankScore float64 // 行业资金排名分 (0-1)
    Macroscore        float64 // 宏观环境分 (0-1)
}
```

#### DailyPick 模型新增字段

```go
type DailyPick struct {
    // ... 现有字段 ...

    IndustryScore float64 `json:"industryScore"` // 行业强度 (0-1)
    ResearchScore float64 `json:"researchScore"` // 研报热度 (0-1)
    MacroScore    float64 `json:"macroScore"`    // 宏观环境 (0-1)
}
```

### DailyPickEngine 改动

1. `RunDailyPick()` 方法开头预取行业排名 + 宏观数据
2. 通过 `scoreStock()` 入参透传给 `StrategyContext`
3. 注册 3 个新策略到 `strategies` 列表
4. 新策略不占用现有 6 因子的权重——通过策略择优机制接入

### AI 上下文改造

#### 现有工具确认可用

- `GetIndustryResearchReport(industryCode)` ✅ 已注册
- `GetStockResearchReport(stockCode)` ✅ 已注册

#### 改造 AI 荐股提示词

修改 `agent/strategy/batch4_fundamental.go` 或 AI 综合分析的 system prompt，增加指令：

> 在分析股票时，请调用 GetIndustryResearchReport 和 GetStockResearchReport 工具获取行业和个股研报信息，在评分时综合考虑以下维度：
> 1. 技术面信号（已有）
> 2. 行业发展趋势（新增）
> 3. 机构研报观点（新增）
> 4. 宏观经济环境（新增）
>
> 输出格式中增加 industryScore (0-10) 和 fundamentalscore (0-10) 结构化字段

### 风险和注意事项

- 行业资金排名和研报 API 依赖外部数据源（东方财富），可能因网络或接口变更失败
- 预取策略降低调用频率，每次 `RunDailyPick()` 各 API 只调用 1 次
- 研报热度策略对冷门股（无研报覆盖）分数天然低，符合预期
- 宏观环境因子所有候选股共享，不影响个股间排名差异
