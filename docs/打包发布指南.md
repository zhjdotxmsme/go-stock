# go-stock 打包发布指南

> 本文档固化本项目桌面端（Wails v2）的本地与 CI 打包流程，以及历史上踩过的坑。
> 2026-09-19 由「新 exe 启动闪退」排查整理。

## 一、本地打包（Windows）

### 标准命令

```bash
# 前置：Go 1.26+、Node 22+、Wails CLI v2.11+
go install github.com/wailsapp/wails/v2/cmd/wails@v2.11.0

# 推荐命令（在仓库根目录执行）
wails build --platform windows/amd64

# 也可以用脚本（内部就是上面这条命令）
./scripts/build-windows.sh
```

产物：`build/bin/go-stock.exe`（约 126MB）。

### ⛔ 禁止用裸 `go build` 打发布包

```bash
# 错误示范：
go build -o go-stock.exe        # ❌
```

`go build` 不带 `-tags desktop,production` 时能编译通过，但启动会弹出
**"Wails applications will not build without the correct build tags"**
错误对话框随即退出——用户看到的就是「启动闪退」。
2026-09-18 的 `build/bin/go-stock.exe` 闪退即此原因。

应急替代（等价于 wails build，但不处理图标/版本资源）：

```bash
go build -tags desktop,production -ldflags "-w -s -H windowsgui" -o build/bin/go-stock.exe
```

### ⚠️ `--clean` 参数会清空 build/bin

```bash
wails build --clean --platform windows/amd64   # 注意！
```

`--clean` 会**删除整个 `build/bin`** 后重建，包括里面运行期生成的
`build/bin/data`（打包版数据库）与 `build/bin/logs`（日志）。

- 给别人打的干净包、CI 打包：可以用 `--clean`。
- 本机日常自用重打包：**不要带 `--clean`**，或先备份 `build/bin/data`。

### ⚠️ 根目录不要留多余的 `.syso` 资源文件

wails build 会自己生成 Windows 资源（图标/版本信息）syso。若仓库根目录已存在
手工用 rsrc 生成的 `rsrc_windows_amd64.syso`，链接会报
**"too many .rsrc sections"** 直接失败。

自定义图标请改 `build/appicon.png`（wails 统一入口），不要再手工生成 syso。

### 打包后自检

```bash
cd build/bin && ./go-stock.exe
# 1. 窗口标题应为行情标题（如 "go-stock A股休市 | …"），而不是标题为 "Error" 的弹窗
# 2. logs/info.log 应有 "starting..." 且持续滚动
```

## 二、CI 打包（GitHub Actions）

配置：`.github/workflows/main.yml`（name: Wails build）。

- **触发**：push 标签 `*-release`（稳定版）/ `*-pre`（预发布）/ `*-dev`（开发版）；另支持 Actions 页面手动触发（workflow_dispatch）。
- **产物**：自动创建 GitHub Release 并上传 exe 与 NSIS 安装包；dev/pre 会自动追加渠道说明并标记 prerelease。
- **固定版本**：Go 1.26 / Node 22.22.2 / Wails CLI v2.11.0（与本地保持一致）。
- **所需仓库 Variables**（Settings → Secrets and variables → Actions → Variables）：
  - `OFFICIAL_STATEMENT`：官方声明文案（可空）
  - `BUILD_KEY`：赞助功能解密 key（可空）

发版流程：

```bash
git tag v1.x.y-release    # 或 -pre / -dev
git push origin v1.x.y-release
```

## 四、历史坑速查

| 现象 | 根因 | 规避 |
| --- | --- | --- |
| exe 启动弹 Error 对话框后退出 | 裸 `go build` 缺 `desktop,production` tags | 用 `wails build` |
| wails build 链接报 `too many .rsrc sections` | 根目录残留手工 syso | 删除/改名多余 syso，图标走 `build/appicon.png` |
| 重打包后本地数据/日志消失 | `--clean` 清空 build/bin | 自用打包不带 `--clean` |
| Android 真机闪退 | migrate 里 `AutoMigrate(v)` 未展开 slice | 必须 `AutoMigrate(v...)`（49a4b42） |
